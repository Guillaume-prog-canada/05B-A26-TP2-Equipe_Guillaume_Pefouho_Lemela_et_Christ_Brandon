###COMPOSANTS BT5:
* **Navbar** : barre de navigation permettant d’accéder aux différentes sections du site.
* **Carousel** : carrousel d’images présentant différentes recettes sur la page d’accueil.
* **Cards** : cartes utilisées pour afficher les recettes, les menus et leurs descriptions.
* **Buttons** : boutons permettant de consulter une recette ou de découvrir les menus.
* **Grid system** (`container`, `row`, `col`) : système de grille permettant d’organiser les recettes et les menus de manière structurée et responsive.
* **Flex utilities** (`d-flex`, `flex-column`, `flex-grow-1`) : classes utilitaires utilisées pour organiser la disposition des éléments de la page.
* **Position utilities** (`position-fixed`, `position-absolute`) : classes permettant de positionner certains éléments, notamment la superposition sombre du carrousel et le bouton de retour en haut.
* **Spacing utilities** (`m-4`, `gap-*`) : classes permettant de gérer les marges et les espacements entre les éléments.
* **Text and color utilities** (`text-white`, `text-dark`, `bg-dark`) : classes permettant de gérer les couleurs du texte et des arrière-plans.
